短视频剪辑 · 完整操作说明

从一条长视频里拆出多条独立竖屏短视频 · 逐步说明每个阶段「做什么、怎么操作、产物是什么、常见问题」。

〇、整体思路

短视频模块的定位是：把一条长视频拆成多条能独立发布的竖屏短视频。六个阶段依次是：

阶段一句话产出
1 视频选择挑一条源视频作为拆条素材项目绑定源素材
2 字幕提取把语音转成带时间戳的字幕stage2/raw.srt
3 内容提取按提示词把字幕重组为 N 条独立短视频stage3/highlights.json
4 内容优化大模型切分长行、修正文字、删冗余字幕stage4_optimize/optimized_highlights.json
5 粗剪合成把每条片段剪成候选成片stage4/coarse_NN.mp4
6 精剪混编加封面/背景/BGM/布局，渲染最终片stage6/final_NN.mp4
阶段 1–5 是内容生产（决定「剪什么、剪多长」），阶段 6 是包装与渲染（决定「长什么样」）。前者出错要重跑，后面几层会跟着作废。

一、创建短视频项目

1.1 从任务进

  1. 先在长视频任务里上传一条原始视频（短视频的素材来自任务）。
  2. 切到顶部「🎞 短视频列表」→ 点「新建短视频任务」，填写项目名称 → 创建。

一个任务下可以建多个短视频项目（例如同一条课程剪成「知识卡」和「故事线」两套）。

二、阶段 1 · 视频选择

2.1 怎么操作

在「视频选择」面板里挑本项目要用的源视频（任务素材列表中的一段），确认后阶段 1 变为完成，下游阶段自动重置为待执行。

换源视频等于换素材：之前所有阶段的产物都会作废，需要从阶段 2 重跑。

三、阶段 2 · 字幕提取

3.1 怎么操作

  1. 选识别模型（中文 paraformer）、语言。
  2. 有专有名词先去「⚙ 设置 → 热词库」配置（对短视频同样有效）。
  3. 点「字幕提取」。会先加载模型（10–30 秒）再识别，进度与已耗时实时显示。

3.2 产物

stage2/raw.srt（字幕）、stage2/raw.json（识别原始结果）

四、阶段 3 · 内容提取（拆条，最关键的一步）

4.1 这步做什么

让大模型读整段字幕，重新组织出 N 条互相独立、各有开场钩子和收尾的短视频。注意不是连续切片，而是跨源位置自由挑选、重新排序的独立片段。

4.2 提示词块（系统提示词模板）

面板与阶段页都有「提示词」下拉/文本框，三个内置模板：

模板适用特点
钩子优先推广、拉新、悬念第一条放最抓人的钩子
主题聚类知识卡、课程拆条按内容主题分成独立知识小卡
起承转合故事、访谈、案例每条都有起承转合的完整故事弧

模板即系统提示词原文；「解析提示词」留空就用模板原文，填了就以你写的为准。

4.3 生成数量与时长区间 人工设置

  • 生成数量（1–10）：本次拆几条。数量多时长就短，一般按「一条讲清一个点」来定。
  • 每条时长下限 / 上限（秒）：单条短视频的时长范围。这个值直接写进提示词，模型会照着来；竖屏短视频常见是 30–60 秒。

4.4 其它选项

  • 发送截图给 AI：勾上会把源视频关键帧截图一起给模型（需要 OCR 支持的模型），有画面信息的素材（如 PPT 讲解）建议勾。

4.5 逐条微调

解析完成后每条片段是一个页签，可单独操作：

  • 单条重跑：只重跑这一条（沿用当前提示词与时长区间）。
  • 删除片段、恢复顺序（模型可能重排了字幕行顺序，一键还原）。
  • 片段预览：在浏览器里按时间段跳转预览这条片段。
改了生成数量或时长区间后，必须重跑阶段 3，否则阶段 4/5 用的还是旧结果。旧产物会被自动作废并提示重跑。

五、阶段 4 · 内容优化

5.1 这步做什么

把每条片段的字幕交给大模型做「精修」：切分过长的句子、修正与音频不符的文字、删掉无意义的行（如「嗯」「那个」）。结果单独存一份，不覆盖阶段 3 的原始解析结果（可随时对照/回退）。

5.2 怎么操作

  1. 点「内容优化」→ 逐条调用模型（条数多时耗时明显）。
  2. 结果里能看到模型删掉的行（标记为「LLM 已删」）并保留展示，方便你核对。
  3. 需要更细的手工调整：每行可编辑文字 / 临时删除 / 拖拽调整顺序，也可以把一行拆成两行或把两行合并；改完可预览该条片段。
  4. 单条重跑：只重跑某一条，其余条保留既有结果。
手工编辑的内容会单独保存成「手动层」，与模型结果并存——重新跑模型不会冲掉你的手工修改，但会作废该条的下游（阶段 5）。

六、阶段 5 · 粗剪合成

6.1 这步做什么

把阶段 4 的每条片段按时间轴剪成候选成片（每条一个 mp4 + 一份字幕），这一步之后才有「一条条视频」可挑。

6.2 怎么操作

  1. 可先设起止位置（%）：在整条源视频里只取某一段范围来剪（默认全量 0–100%）。
  2. 点「粗剪合成」→ 异步执行，页面显示进度、已完成条数与每条耗时；可只重跑某一条。

6.3 成片字幕（可选）

粗剪完成后可对成片再识别一次字幕，得到连续字幕（SRT），并支持逐句改字——这样烧进画面的字幕与你的口播完全一致。改完可以导出字幕文件。

粗剪产物是阶段 6 的输入。删掉某条粗剪会作废它的下游（精剪混编）。

七、阶段 6 · 精剪混编（最终成片）

7.1 参数分组

组控制什么
布局视频、字幕、封面、背景、导师文字、导师头像、标题、封面标题各区域的位置与大小；视频源裁剪支持 16:9 锁定
导师文字昵称与标题的文本、字体、字号、颜色、描边
字体字幕字号、颜色、描边、背景块、对齐
输出分辨率（720p / 1080p / 跟随源）与编码
音频BGM 与音量
素材封面图、背景图、导师头像（每个槽位可上传）

7.2 哪些内容是「可选」的（重点）

布局里的每个区域都有一个勾选框（启用此区域）。只有勾选了，对应内容才会出现在成片里；不勾选就不会输出——不是画了但看不见，而是渲染时整块跳过。

元素所在不勾选时
导师文字（导师抬头、昵称与标题文字）布局 → 导师文字区域成片里不出现任何导师抬头/昵称/导师标题文字
导师头像布局 → 导师头像区域成片里不出现头像（圆形或矩形）
标题（输出到画面的标题）布局 → 标题区域成片里不出现标题文字
封面标题（封面片头段上的标题）布局 → 封面标题区域封面片头段不叠标题文字（封面图本身照常显示）
背景 / 字幕布局 → 背景、字幕区域同样不输出（背景图不铺、字幕不烧）
视频布局 → 视频区域—（视频是内容本体，恒定输出，勾选框对它无意义）

什么时候应该关掉它们

这两种情形下，把对应项取消勾选，避免和已有画面里的文字重复：

  1. 封面已经带标题 —— 封面图本身已经排好了标题文字，就不要再叠一层： 取消勾选「封面标题」（以及不需要的画面「标题」）。
  2. 背景图里已经带标题、导师头像、导师抬头相关文字 —— 背景是「画好的整版设计图」， 再叠系统生成的元素就会出现重影/挡字： 取消勾选「标题」「封面标题」「导师头像」「导师文字」， 只保留「视频」与需要的「字幕」。
做法：先上传你设计好的封面 / 背景图 → 预览一眼 → 把重复的元素取消勾选 → 再导出。 这样成片里的文字完全由你设计稿说了算，系统不再叠加第二份。
注意：素材槽位里传了图不等于会显示——最终是否输出由对应区域的勾选框决定。 比如上传了导师头像但取消了「导师头像」勾选，成片里依然不会出现。

7.3 常用功能

  • AI 智能布局：让模型根据画面内容建议各区域摆放。
  • 检测区域：检测视频主体区域并一键填充到背景/布局。
  • 参数模板：把调好的参数存成模板复用（tasks/_global_short_video_fine_profiles.json）。
  • 预览 / 导出：先出预览确认，再导出最终片（渲染较慢，建议先预览）。

7.4 逐条处理

阶段 6 是逐条操作的：顶部有片段页签，切到哪条就改哪条的参数，导出也是按条导出。

八、流程配置（自动执行）

8.1 它能做什么

项目页顶部的「⚙ 流程配置」把各阶段参数集中在一处，配好后一次点「▶ 执行」，系统按顺序自动跑——不用守着点每个按钮。

8.2 可配置项

配置项说明
提示词块阶段 3 的系统提示词模板（钩子优先 / 主题聚类 / 起承转合）
生成数量 人工设置本次拆几条（1–10）
时长上下限 人工设置每条短视频的秒数区间
运行阶段从哪一阶段开始跑、跑到哪一阶段停
各阶段参数识别模型/语言/热词、截图开关、粗剪起止位置等

8.3 执行

  1. 填好参数 → 点「▶ 执行」。
  2. 弹出的确认框会列出生成数量、时长区间、提示词块、起止阶段——确认无误再跑。
  3. 右上角状态条显示当前阶段、进度与逐条日志，可随时「⏹ 停止」。
自动执行止于「粗剪合成」——不会自动进入「精剪混编」。因为精剪需要你逐条挑封面/背景/BGM，交给机器没有意义。

九、执行日志

阶段栏最下方「📜 执行日志」记录每个主要操作的时间、耗时、成功/失败与错误信息。

  • 短视频操作：按操作类型过滤（选择源视频 / 提取字幕 / 内容提取 / 内容优化 / 粗剪合成 / 精剪混编 …）
  • 状态：成功 / 失败 / 运行中
  • 模式：选「⚙ 自动」只看流程配置自动执行产生的那一轮

底部可翻页。排查问题的顺序：筛「❌ 失败」→ 看报错原文 → 回到对应阶段修 → 用「▶ 从本阶段开始」续跑。

十、参数会被自动记住

每次保存剪辑参数，系统都会：

  1. 写入当前项目（project.json）
  2. 另外自动存一份全局快照：tasks/_global_short_video_params.json

第 2 份是给「换项目 / 换机器 / 新系统」用的——新环境直接沿用最近一次的参数，微调即可。

「❓ 帮助 → 导入短视频参数」可用内置默认参数填充当前项目的剪辑参数与项目配置（素材不受影响）。

十一、常见问题

解析出来的片段都不好看 / 不是我想要的

先换提示词块（钩子优先 / 主题聚类 / 起承转合），再调时长区间；仍然不行就手动改某一条或单条重跑。

阶段 4 提示要先完成阶段 3

内容优化依赖阶段 3 的解析结果。回阶段 3 跑完（或改完参数重跑）再回来。

改了阶段 3 的数量，为什么阶段 4 的东西没了？

上游产物变了，下游会自动作废——这是「防止用旧结果出片」的保护。重新跑阶段 4/5 即可。

粗剪很慢

每条片段一次 ffmpeg 切片，条数越多越慢。可以只重跑某一条，不必全量重跑。

字幕烧进画面后和口播对不上

在阶段 5 用「成片字幕提取」重新识别并逐句改字，导出连续字幕后再进阶段 6。

自动执行跑到一半停了

看执行日志里「⚠️ 已跳过 / ❌ 出错」的条目；多半是某阶段缺少前置产物（如没选源视频）。补完后用「▶ 从本阶段开始」续跑。
