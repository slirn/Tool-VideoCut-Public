一、大模型设置

1.1 它管什么

整个工程所有「用到大模型」的环节 — 字幕修订、优化字幕（不明确字词 + 断句整理）、精剪校对、短视频内容提取 / 编排、热词 AI 分析 — 用的都是这里注册的当前模型。没配好模型，这些阶段会报「未配置大模型」。

1.2 添加一个模型

  1. 「⚙ 设置 → 大模型设置」打开弹窗，拉到下方「添加模型」表单。
  2. 模型名：服务商的模型 ID，如 deepseek-chat、MiniMax-M3。
  3. 厂商：显示用的备注名，如「DeepSeek」「阿里云百炼」。
  4. 协议：按服务商文档二选一 — OpenAI 兼容（请求发到 {Base URL}/chat/completions）或 Anthropic（请求发到 {Base URL}/v1/messages）。
  5. Base URL：接口根地址，如 https://api.deepseek.com/v1。
  6. Key 环境变量：填变量名（如 DEEPSEEK_API_KEY），不是 Key 本身。
  7. 支持图片：多模态模型才勾 — 精剪合成的「AI 智能布局」要分析视频截图，需要此项。
  8. 点「➕ 添加」，然后点该行的「测试」发一个最小请求验证连通，最后点「⭐ 设为当前」启用。

1.3 管理已有模型

已注册列表每行四个按钮：⭐ 设为当前（全局生效）、测试（连通性验证，结果会显示在表单下方）、编辑（回填表单改配置）、删除。带 ⭐ 高亮的是当前模型。

Key 的安全设计（务必了解）：界面从头到尾只保存「环境变量名」，不保存也不显示 Key 本体。真正的 Key 放在服务器系统环境变量里（如 Windows 的 DEEPSEEK_API_KEY）。换 Key 只需改环境变量，界面一个字都不用动；界面 / 配置文件泄露也不会带走 Key。
协议选错的典型症状：调用一直 404 — 多数是协议与 Base URL 不匹配（例如 Anthropic 协议的网关配了 OpenAI 风格的 URL，或反之）。对照服务商文档检查这两项。
弹窗中部有「📊 Token 用量」区块（当前汇总快照），点「打开用量统计页」直达下面第三节的用量页。

二、系统设置

2.1 大模型并发 Worker 数（1–8）

字幕修订 / 优化字幕 / 精剪校对这类「几百行字幕分批调大模型」的阶段，同时发出的并行请求数。

  • 调大 → 阶段耗时近似除以并发数（长视频收益最明显：几百行从串行几十分钟缩到最慢一批的时长）。
  • 调太大 → 撞服务商限流（429），系统会自动全体退避等待再重试 — 能跑完，但反而慢。
  • 改完点「💾 保存」立即生效，无需重启服务。

不知道填多少？点「🔍 检测建议值」：对当前模型发约 20 个微小请求实测限流边界（约 10–30 秒），给出各并发档的成功 / 限流 / 失败 / 耗时表格和建议值，照抄即可。

2.2 上下文窗口 · 批量打包

字幕分批不再按固定条数切，而是按「上下文窗口 − 输出预留 − 安全余量」逐行累加整行打包：短行多装、长行少装，用满窗口、减少调用次数。窗口大小由「📐 探测上下文」自动获取，三层探测：

  1. 先查模型元数据；
  2. 再发一个超长请求，从网关的拒绝报文里读出实际上限；
  3. 仍拿不到就 64K / 32K / 16K / 8K 阶梯实测。
费用说明：被拒的探测请求不计费；首个成功的请求按实际 tokens 计（一般不超过一次普通调用）。探测结果缓存在服务器，跨重启有效，换模型后再点一次即可。

三、Token 用量

3.1 汇总

入口：「⚙ 设置 → 📊 Token 用量」（或大模型设置弹窗里的跳转按钮）。汇总卡三块：

  • 总计：输入 / 输出 token、调用次数（网关没回 usage 的按字符估算，单独标出笔数）；
  • 按模型：每个模型的输入 / 输出 / 次数，按消耗从大到小；
  • 按任务：消耗最大的前 5 个任务，附阶段级分解。

3.2 明细与筛选

下方「📋 调用明细」逐笔列出：时间 / 模型 / 任务 / 阶段 / 输入 / 输出 / 耗时。带 ≈ 的是估算值。

筛选条支持组合使用，输入后直接回车即筛选（或点「🔍 筛选」；「↺ 重置」清空全部条件）：

条件说明
任务 ID留空 = 全部任务
模型 / 阶段下拉选项自动来自日志里出现过的值
起止日期含当天；只填一端也行
耗时区间（秒）闭区间，用来专挑慢请求

底部翻页：‹ › 前后翻页，每页 50 / 100 / 200 条可切换。

阶段名速查：大模型分析字幕 = 字幕修订；断句整理、优化字幕、精剪校对、热词提取、连通性测试各占一个阶段名；短视频的以「短视频-」开头（如 短视频-内容提取）。

四、热词库

4.1 它管什么

人名、术语、产品名这类专有名词的词库。字幕生成时用它做识别偏置 — 词库里有「Slirn」，识别就不会写成「斯林」。公共库对所有任务生效。

4.2 手动维护

选分类 → 输入框加词（回车 / 「➕ 添加」）；词块上的 ✕ 删单个，分类工具栏「☑ 全选 / ⇄ 反选 / 🗑 删除选中」批量处理。

4.3 AI 热词分析

页面下方的折叠块「🤖 AI 热词分析」，适合视频专业词汇密集、懒得手打的场景：

  1. 展开后填需求描述（例：「这是一档讲 RAG 与向量数据库的播客，主持人叫张老师」）；
  2. 可选：粘贴文章 / 字幕 URL 让 AI 连内容一起分析（还可填区域提示，如 #article 或「找正文部分」）；
  3. 点「🔍 分析」→ 候选词以词块形式出现，点击选中要采纳的；
  4. 「➕ 选中的加入任务」（只给当前任务的字幕生成用）或「📚 选中的加入公共库」（全局）。
AI 分析依赖大模型 — 先完成第一节的大模型设置。

五、快捷键

「⚙ 设置 → ⌨ 快捷键」打开自定义弹窗：每个操作一个键帽，点击键帽 → 按新键即完成更换；Esc 取消录制；不支持组合键。改乱了点「↩️ 恢复默认」。快捷键作用于预览播放器等高频操作，熟练后可以完全脱离鼠标看片。

六、登录日志

「⚙ 设置 → 📜 登录日志」列出本人最近的登录事件：✅ 成功 / ❌ 失败（含原因）/ 🚪 登出，每条附时间与 IP。

最典型的用途是排查「我怎么突然被踢下线了」— 本系统同一账号只保持一个会话：别处登录会把当前会话踢掉。在这里看到一条不是你操作的成功登录记录，就说明账号在别处被使用了，建议立刻改密码。

七、安全清单

  • 默认管理员账号 admin / admin123!@# — 登录后第一件事到右上角用户名 →「用户管理」改掉，尤其计划用 --listen 对局域网 / 公网开放时；
  • API Key 只放服务器环境变量，界面里永远只填变量名（见 1.3）；
  • 用量账本、登录日志都在服务器本地，不外发。
