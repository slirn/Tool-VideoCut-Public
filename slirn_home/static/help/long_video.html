长视频剪辑 · 完整操作说明

VideoCut 工作台 · 从一条原始视频到可发布的成片，逐步说明每一阶段「做什么、怎么操作、产物是什么、常见问题」。

〇、开始之前

0.1 准备环境

  • ffmpeg：剪辑与渲染全程依赖它。命令行执行 ffmpeg -version 能看到版本号即正常。
  • 模型：FunASR 与 ASR 模型在首次识别时自动下载（数 GB），之后离线可用。
  • 大模型：字幕修订、内容优化等环节需要配置模型（顶部「⚙ 设置 → 大模型设置」），密钥读环境变量。

0.2 登录与账号

浏览器打开工作台后进入登录页。默认管理员账号 admin / admin123!@#（首次启动自动创建），登录后请立刻在「设置 → 用户管理」里改掉密码。

同一账号只能在一个终端保持登录：换浏览器或换机器登录会把上一个会话踢下线（这是设计如此，用于防止账号被多处同时使用）。

一、创建任务

1.1 新建任务

  1. 在工作台首页点「新建任务」，填写任务名称。
  2. 上传原始视频（mp4 / mov / mkv 等）。视频是后续所有阶段的唯一来源，建议先用一段 1–3 分钟的样片跑通流程，再上长视频。
  3. 可选：填充分词，用于「切分修剪」阶段按语义保留片段。

1.2 进入工作台

任务列表里点任务卡片进入工作台。左侧是阶段栏（六个阶段 + 执行日志），右侧是当前阶段的工作区。

阶段栏顶部有「完成后，自动打开下一阶段界面」开关。勾上后，当前阶段做完会自动切到下一阶段，省去手动点；不勾则停在原页由你自己看。

二、阶段 1 · 字幕生成

2.1 这步做什么

用 FunASR 把视频语音转成带时间戳的字幕。这是后面所有步骤的基础——没有字幕就无法修订、无法切分。

2.2 怎么操作

  1. 在字幕面板选识别模型（中文用 paraformer 即可）、语言。
  2. 需要识别专有名词（人名、产品名、术语）时，先去顶部「⚙ 设置 → 热词库」加词条，识别准确率会明显提升。
  3. 多人对话的视频可勾选「区分说话人」——后续可以按人批量删除或只保留某个人。
  4. 点「生成字幕」。进度条与已耗时在面板里实时显示；视频越长越慢（通常几分钟到几十分钟）。

2.3 产物

outputs/subtitle.json（结构化字幕）、outputs/subtitle.srt（通用字幕格式）

字幕质量直接决定后续切分质量。识别完先扫一眼有没有大段乱码或时间轴错位，必要时调整模型/热词后重跑，别急着往下走。

三、阶段 2 · 字幕修订

3.1 这步做什么

让大模型逐条审阅字幕：修正错别字、标点、明显的识别错误，并按语义把长句切开。这一步的产物是后面「切分修剪」的决策依据。

3.2 怎么操作

  1. 选严谨性：人工设置
    • 高：逐条精修，适合正式课程/对外内容；耗时最长。
    • 中：只改明确错误，默认档位，性价比最高。
    • 低：只动严重问题，适合粗剪试片。
  2. 「跳过建议类别」：如「标点」「错别字」，让模型专注别的。
  3. 「自动关联人员 ID」：开了区分说话人时，把字幕行对应到具体的人（后续可按人操作）。
  4. 「默认接受所有建议」：全量自动采纳。若想逐条人工确认，先别勾。

逐条审阅

不勾「默认接受」时，右侧会列出每条建议（原文 → 建议文本），可逐条接受/拒绝。处理完记得点「保存决策」——不保存的话下游拿不到决策。

这一阶段经常拦住后续：「切分修剪」会检查是否还有未决策的条目，有残留就拒绝执行。看到「还有 N 条未决策，请先保存全部决策」就回这里把剩下的处理完。

四、阶段 3 · 切分修剪

4.1 这步做什么

把字幕按修订后的文本重新切成「保留段 / 删除段」，形成粗剪的时间轴。这一步是内容取舍的主战场。

4.2 怎么操作

  1. 默认决策：保留 或 删除——模型无法判断的段落按这个走。建议先「保留」，再人工删掉不要的。
  2. 删除某些说话人：填说话人 ID（如 1,3），这些人的所有记录整段剔除。适合访谈里只留主讲。
  3. 「自动关联人员 ID」：同阶段 2，建议保持一致。
  4. 执行后得到切分清单，可在页面上直接增删改每段的起止。
提示：切分结果不满意时，改回阶段 2 调整字幕、再重跑阶段 3，比在阶段 3 手工抠时间戳高效得多。

五、阶段 4 · 粗剪合成

5.1 这步做什么

按保留区间把原视频拼成一条粗剪成片（未做字幕精修、未加包装）。这一步必做，后面阶段都基于它。

5.2 怎么操作

点「粗剪合成」→ 异步执行，页面显示进度与已耗时。产物：

outputs/rough_compose.mp4

合成期间不要刷新页面或关服务；粗剪通常几分钟到十几分钟（取决于总时长与机器性能）。

六、阶段 5 · 优化字幕

6.1 这步做什么

粗剪成片重新识别一遍字幕（此时视频已被剪短，口语更密），再由大模型挑出「不明确字词」给出替换建议。

6.2 怎么操作

  1. 点「优化字幕」→ 先跑识别，再等模型出建议。
  2. 逐条确认替换；急用可勾「默认接受所有替换」。
  3. 点「确认保存」。
这一步是可选的，但做过之后成片字幕的准确度通常更好；如果时间紧，可以先跳过，后续再回来补。

七、阶段 6 · 精剪合成（最终导出）

7.1 这步做什么

把粗剪成片做成最终成片：加封面、背景图、背景音乐、字幕样式，可整篇导出也可只导出一段区间。

7.2 参数怎么理解

参数组控制什么
布局视频、字幕、封面、背景各区域的位置与缩放；视频源裁剪（crop）支持「16:9 锁定」防止变形
字体字号、颜色、描边、背景块、对齐方式与偏移
输出分辨率（720p / 108p / 跟随源）、编码
音频BGM 开关、音量（dB，-8 左右自然）、淡入淡出
预览只影响「生成预览」的截取区间，不影响最终导出
检测区域AI 检测出的主体区域，可一键套用到背景等区域

7.3 常用操作

  • 素材：封面图、背景图、背景音乐可上传，也可「自动获取」上游已有产物。
  • 参数模板：把调好的六组参数存成命名模板，下次直接套用（tasks/_global_fine_profiles.json）。
  • 生成预览：先出短片段确认效果再导出整片，省时间。
  • 导出：选「🎬 出整个片」或「✂️ 按区间导出一段」，确认后后台渲染。
导出是全流程最慢的一步（重编码整片，可能几十分钟到数小时）。先出预览确认参数，再导出。

八、流程配置（自动执行）

8.1 它解决什么问题

手动跑六个阶段要一直守着。流程配置把参数集中在一处，配好后一次点「▶ 执行」，系统按顺序自动跑到你指定的阶段。

8.2 怎么用

  1. 打开工作台顶部的「⚙ 流程配置」面板。
  2. 逐阶段设置参数（字幕生成是否区分说话人、修订严谨性、切分默认决策、优化是否全接受、精剪导出方式等）。
  3. 选「运行模式」：停在指定阶段 / 一键跑到底。
  4. 选「完成到哪个阶段停」——例如停在「字幕修订后停」等人审阅。
  5. 点「▶ 执行」。右上角出现状态条，显示当前阶段、进度与逐条日志；随时可「⏹ 停止」。

续跑

每个阶段标题右侧都有「▶ 从本阶段开始」——跳过已完成的阶段从指定处续跑。执行记录里能看到上次跑到哪了。

内置模板

面板左上角可切换「人工全审 / 半自动 / 全自动」三套内置模板：人工全审 = 字幕修订后停；半自动 = 粗剪合成后停；全自动 = 跑到底。套用后再微调即可。

九、执行日志

9.1 看什么

左侧阶段栏最下方「📜 执行日志」记录了本任务所有阶段的执行历史：起止时间、耗时、成功/失败、错误信息，以及该次是否由流程配置自动触发（⚙ 自动标记）。

9.2 怎么筛

  • 阶段：只看字幕生成 / 粗剪合成 / 精剪导出 等某几类操作
  • 状态：成功 / 失败 / 运行中
  • 模式：⚙ 自动 只看流程配置自动执行产生的那一轮
  • 时间：今天 / 近 7 天 / 近 30 天 / 全部
  • 关键词：搜错误信息里的关键词

底部可翻页（每页 20 条）。

排查问题的顺序：先在日志里筛「❌ 失败」看报错原文 → 再按错误里的文件名/阶段名回到对应阶段处理 → 改完用「▶ 从本阶段开始」续跑。

十、设置菜单

10.1 ⌨ 快捷键

自定义各阶段常用操作的按键（长短视频均生效）。保存后立即生效，重开页面也保留。

10.2 📚 热词库

维护专有名词词表（人名、品牌、术语）。在字幕生成之前配置收益最大；也可在生成后补录再重跑识别。

10.3 大模型设置

配置要用的模型与接口（OpenAI 兼容 / Anthropic 协议）。密钥填环境变量名（如 DASHSCOPE_API_KEY），真实密钥写在环境变量里，不会存进数据库。

10.4 📥 导入参数

「❓ 帮助 → 导入长视频参数」会用内置默认参数填充当前任务的精剪参数（素材路径不受影响），适合新环境快速起步。

十一、参数会被自动记住

每次改动精剪参数，系统都会：

  1. 写入当前任务：tasks/<task_id>/fine_compose.json
  2. 另外自动存一份全局快照：tasks/_global_fine_params.json

第 2 份是给「换任务 / 换机器 / 新系统」用的——新环境直接沿用最近一次的参数，微调即可，不用从头调。

十二、常见问题

「还有 N 条未决策，请先保存全部决策」

阶段 2 字幕修订有遗留没处理的建议。回去逐条处理（或勾「默认接受所有建议」重跑）并点「保存决策」。

阶段 4 提示缺少依赖产物

上游阶段没跑完。检查日志里前序阶段是否失败，失败就先修再重跑；想直接续跑就用「▶ 从本阶段开始」前先确认前序产物存在。

粗剪/导出很慢

是正常的（整片重编码）。先用「生成预览」验证参数，再导出整片；确认机器上没有其他重任务在跑。

识别结果大面积乱码

先换模型（paraformer → sensevoice）试试，再补热词库重跑。

换了浏览器就登不上

单账号单会话的设计：新登录会把旧会话踢掉，属正常。用新浏览器登录即可。
