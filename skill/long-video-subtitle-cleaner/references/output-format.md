# 输出格式说明

当前技能的默认中间/最终文本格式如下：

```text
序号. [开始时间 - 结束时间] 字幕文本
```

示例：

```text
27. [00:01:11,830 - 00:01:18,940] 然后呃我们回到 IP 这个东西 IP 本身的目前以我们训练营的来说
```

约束：

- 序号使用阿拉伯数字，从 `1` 开始递增。
- 方括号中保留原始 `SRT` 的开始时间和结束时间。
- 时间中的毫秒分隔符保留 `,`。
- 区间连接符统一使用 ` - `。
- 字幕正文保持原顺序，不改字，不改时间。
- 中间文件不做语义清洗。
- 最终文件只允许删行，不允许改写保留下来的那一行时间和文本。

如果后续拿到了正式参考样例：

- 优先修改脚本中的 `format_entry()`。
- 不要修改“保留时间值和保留文本”的基本原则。

## 删除内容比对文件格式

删除内容比对文件默认格式如下：

```text
原序号. [开始时间 - 结束时间] 原文本 || 删除原因: 原因说明
```

示例：

```text
7. [00:00:15,140 - 00:00:15,800] 能看到吗？ || 删除原因: 简短问答互动
```

用途：

- 给人工确认“这轮清洗具体删了哪些内容”。
- 不参与最终成片，只用于审核和调规则。

## 双栏对照文件格式

双栏对照文件默认使用 Markdown 表格，并严格保持中间文件原始顺序：

```md
| 中间文件 | 处理结果 |
| --- | --- |
| 1. [00:00:00,110 - 00:00:01,110] ~~太丰富了~~ | 删除: 碎片化短句 |
| 2. [00:00:02,010 - 00:00:02,650] 我讲的比较浅 | 保留: 1 |
```

约束：

- 左栏为中间文件原始行。
- 右栏为该原始行对应的处理结果。
- 删除项原文加 Markdown 删除线。
- 保留项右栏只显示新的编号。
- 总数据行数应与中间文件条目数一致。
- 这是审核辅助文件，不回写到最终输出。

## 重复问题专用文件格式

重复问题专用文件只保留出现了重复字、重复词或重复短语的最终行：

```text
2. [00:00:45,330 - 00:00:49,670] 这个我我不太着课
替换后: 2. [00:00:45,330 - 00:00:49,670] 这个我〿不太着课
问题: 单字重复: "我" 连续出现 2 次
```

约束：

- 正常最终输出文件不做 `〿` 替换。
- `repeat-only` 文件只保留发生重复替换的问题行。
- 同一行如果有多个重复问题，统一写在 `问题:` 后面。

## 连续时间轴 SRT 格式

连续时间轴字幕文件使用标准 SRT：

```srt
1
00:00:00,000 --> 00:00:00,640
我讲的比较浅

2
00:00:00,640 --> 00:00:04,980
这个我〿不太着课
```

规则：

- 序号沿用最终输出顺序，从 `1` 开始递增。
- 每条新时长沿用该条原始片段时长。
- 新时间轴连续衔接，中间不保留原始空白区间。
- 当某条字幕超过 20 个字时，按每 20 个字拆分成多条连续字幕。
- 文本使用适合剪映排查的版本，即允许写入 `〿` 这类重复标记符。
