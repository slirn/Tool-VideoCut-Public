# Long Video Subtitle Cleaner

这个技能用于处理在线授课长视频字幕，固定分成两步：

1. 先把 `SRT` 转成“目标格式中间文件”。
2. 再基于中间文件删除冗余内容，生成最终文件。
3. 同时输出一份“删除内容比对文件”，用于确认从中间文件删掉了哪些行。
4. 可选输出一份“双栏对照文件”，严格按中间文件原始顺序逐条展示处理结果。
5. 可选输出一份“重复问题专用文件”，只保留存在重复字/词/短语的最终行，供视频剪辑定位。
6. 可选把最终输出转换成“连续时间轴 SRT”，供剪映导入字幕。

## 处理原则

- 保留讲师讲课主线内容。
- 删除口水词、口头禅、单独语气词。
- 删除重复的话语和重复片段。
- 删除语义模糊、逻辑混乱、无法独立成立的表达。
- 删除课堂互动内容，例如：
  - 提问和回答
  - “能看到吗”“听得到吗”
  - 调整屏幕、PPT、设备、网络、声音
  - 串场、寒暄、点名、提醒进群、提醒操作
- 不改变保留下来的字幕文本。
- 不改变保留下来的开始时间和结束时间。
- 不补写原字幕中不存在的新内容。
- 必须处理完整字幕，不允许中途截断。

## 输出格式

当前默认目标格式为单行文本：

```text
1. [00:01:11,830 - 00:01:18,940] 然后呃我们回到 IP 这个东西 IP 本身的目前以我们训练营的来说
```

注意：

- 这里只参考目标样例里的“单行时间戳格式”。
- 时间值必须沿用原始 SRT 中该条字幕的开始时间和结束时间。
- 不能像错误样例那样改写时间戳。

## 推荐流程

### 第一步：生成中间文件

运行：

```powershell
python slirn\skill\long-video-subtitle-cleaner\scripts\srt_to_intermediate.py `
  --input slirn\material\result_20260618_140706.srt `
  --output slirn\output\result_20260618_140706.intermediate.txt
```

作用：

- 逐条读取 SRT。
- 合并同一字幕块中的多行正文。
- 转成单行目标格式。
- 不做语义删改。

### 第二步：基于中间文件生成最终文件

运行：

```powershell
python slirn\skill\long-video-subtitle-cleaner\scripts\clean_intermediate_subtitles.py `
  --input slirn\output\result_20260618_140706.intermediate.txt `
  --output slirn\output\result_20260618_140706.cleaned.txt `
  --removed-output slirn\output\result_20260618_140706.removed.txt `
  --review-output slirn\output\result_20260618_140706.review.md `
  --repeat-output slirn\output\result_20260618_140706.repeat-only.txt
```

作用：

- 保留中间文件中符合授课主干的行。
- 删除冗余、互动、重复、混乱内容。
- 输出最终结果。
- 额外输出一份“删除内容比对文件”。
- 可选输出一份“双栏对照文件”。
- 可选输出一份“重复问题专用文件”。

### 比对文件说明

比对文件用于人工复核本轮清洗删掉了什么。

格式示例：

```text
7. [00:00:15,140 - 00:00:15,800] 能看到吗？ || 删除原因: 简短问答互动
12. [00:00:30,910 - 00:00:38,130] 这个大小可以直接开那个有个小点下载旁边有个演示啊 || 删除原因: 课堂互动或设备调试内容
```

说明：

- 左侧保留中间文件中的原始序号和原始时间戳。
- 文本保留中间文件中的原始内容。
- 末尾追加删除原因，方便人工判断规则是否合适。

### 双栏对照文件说明

双栏对照文件用于按中间文件原始顺序逐条审核每一行的处理结果。

格式示例：

```md
| 中间文件 | 处理结果 |
| --- | --- |
| 1. [00:00:00,110 - 00:00:01,110] ~~太丰富了~~ | 删除: 碎片化短句 |
| 2. [00:00:02,010 - 00:00:02,650] 我讲的比较浅 | 保留: 1 |
```

说明：

- 左栏固定显示中间文件的原始行。
- 删除项在左栏原文上加删除线，便于人工扫读。
- 右栏对保留项只显示新的编号，不重复全文。
- 右栏对删除项显示删除原因。
- 双栏文件的总数据行数应与中间文件条目数一致。
- 推荐输出为 `.md`，在编辑器里会更清晰。

### 重复问题专用文件说明

这个文件只保留需要做重复替换检查的最终行，不写入正常行。

格式示例：

```text
2. [00:00:45,330 - 00:00:49,670] 这个我我不太着课
替换后: 2. [00:00:45,330 - 00:00:49,670] 这个我〿不太着课
问题: 单字重复: "我" 连续出现 2 次
```

说明：

- 第一行是正常最终输出中的原文。
- 第二行是替换后的定位版本，默认占位符为 `〿`。
- 第三行列出检测到的重复问题类型。
- 没有重复问题的正常行，不写入这个文件。

### 连续时间轴 SRT

把最终输出文件转换成新的 `SRT` 时：

- 重新按保留片段顺序生成连续时间轴。
- 每条字幕的新时长，沿用该条在原始时间戳中的持续时长。
- 新字幕的开始时间等于上一条字幕的结束时间。
- 若某条字幕超过 20 个字，则按每 20 个字拆成一条新的连续字幕。
- 导出到 `SRT` 时，对重复字/词/短语应用特殊符号替换，便于剪映内查找。

运行：

```powershell
python slirn\skill\long-video-subtitle-cleaner\scripts\export_continuous_srt.py `
  --input slirn\output\result_20260618_140706.cleaned.txt `
  --output slirn\output\result_20260618_140706.continuous.srt `
  --repeat-output slirn\output\result_20260618_140706.continuous.repeat.txt `
  --max-chars-per-caption 20
```

输出：

- `continuous.srt`：连续时间轴字幕文件，适合导入剪映。
- `continuous.repeat.txt`：只记录连续字幕里哪些文本被替换了特殊符号。

## 什么时候需要看参考文件

- 需要了解默认格式和字段定义时，读取 `references/output-format.md`。
- 需要了解清洗时的删除/保留标准时，读取 `references/cleaning-rules.md`。

## 技能使用提醒

- 如果用户提供了新的目标样例文件，优先按新样例调整输出模板。
- 如果用户只说“参考样例”，但样例文件为空，先沿用当前默认单行格式。
- 若识别到字幕编码异常，优先尝试 `utf-8-sig`，再回退 `utf-8` 和 `gb18030`。
- 若保留行中出现连续重复字/词/短语，正常最终文件保持不替换；如需剪辑定位，输出 `repeat-only` 文件查看替换版本。
- 若要导入剪映做成片字幕，优先输出连续时间轴 `SRT`，并在该 `SRT` 中写入重复标记符。
