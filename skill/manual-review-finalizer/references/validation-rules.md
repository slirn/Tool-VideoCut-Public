# 重复与异常名词校验规则

校验目标：

- 重字
- 重复词
- 重复短语
- 异常名词
- 同音误识别词

## 合理叠词默认放过

- `看看`
- `想想`
- `讲讲`
- `试试`
- `研究研究`
- `讨论讨论`

## 口语卡顿型重复默认标记

- `我我`
- `他他`
- `然后然后`
- `这个这个`

## 异常名词 / 同音误识别示例

- `短句` -> `短剧`
- `短局` -> `短剧`
- `短距` -> `短剧`
- `短缺` -> `短剧`
- `短学` -> `短剧`
- `慢剧` -> `漫剧`
- `视脚` -> `视觉`

## 维护方式

- 新增异常词时，直接追加一行：
  - `` `错误词` -> `建议词` ``
- 脚本会自动读取这类映射，无需改 Python 代码。

## 输出方式

- 原文
- 标记后文本
- 问题说明
- 如存在词语建议，额外输出建议词

## 不做这些校验

- 句子有没有说完
- 代词是否悬空
- 半句承接词
- ASR 导致的整体不通顺
