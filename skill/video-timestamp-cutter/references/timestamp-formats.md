# 时间戳格式参考

## 支持的格式

### 1. SRT 格式（标准）

```srt
1
00:00:10,500 --> 00:00:15,200
这是第一段字幕文本

2
00:00:20,100 --> 00:00:25,800
这是第二段字幕文本
```

时间格式：`HH:MM:SS,mmm` 或 `HH:MM:SS.mmm`

### 2. 清洗技能输出格式

```text
1. [00:01:11,830 - 00:01:18,940] 然后呃我们回到 IP 这个东西
```

或只有时间戳：

```text
1. [00:01:11,830 - 00:01:18,940]
```

### 3. JSON 格式

```json
[
  {"start": 10.5, "end": 15.2, "text": "字幕文本"},
  {"start": 20.1, "end": 25.8, "text": "第二段文本"}
]
```

或：

```json
{
  "segments": [
    {"start": 10.5, "end": 15.2},
    {"start": 20.1, "end": 25.8}
  ]
}
```

### 4. 时间范围格式（命令行参数）

通过 `--start` 和 `--end` 参数直接指定：

```bash
python cut_by_srt.py --input video.mp4 --srt video.srt --output out.mp4 --start 10.5 --end 65.3
```
